========================================================
  XP-236B LABEL STUDIO  —  for macOS
========================================================

Design and print asset labels (code + QR + logo + text,
English & Persian/Dari) on the Xprinter XP-236B.

--------------------------------------------------------
WHAT YOU NEED
--------------------------------------------------------
- A Mac (Apple Silicon: M1/M2/M3/M4).
- The Xprinter XP-236B, connected by USB and turned ON.
- Label roll loaded.

--------------------------------------------------------
BEFORE YOU START — INSTALL THE PRINTER DRIVER
--------------------------------------------------------
Download the Xprinter XP-236B macOS driver and install it:
   https://www.xprintertech.com/  ->  Support / Download
   (search for XP-236B, macOS driver .pkg)
Plug the printer in by USB and turn it on.

--------------------------------------------------------
FIRST TIME — 2 STEPS
--------------------------------------------------------
Because this app didn't come from the App Store, macOS
blocks it on the first launch. To get past that, OPEN THE
FIRST FILE BY RIGHT-CLICKING IT:

1) RIGHT-CLICK  "1. Setup (run first).command"  ->  Open
   -> in the warning box click  Open.
   It installs the printer driver (asks for your Mac
   password) and sets up the printer. Do this once.

2) RIGHT-CLICK  "2. Start Label Studio.command"  ->  Open
   -> click  Open.
   Label Studio opens in your web browser. Design your
   label and click Print.

After the first time, you can just DOUBLE-CLICK
"2. Start Label Studio" to use it.

--------------------------------------------------------
DAY-TO-DAY USE
--------------------------------------------------------
- Double-click "2. Start Label Studio".
- A Terminal window opens (that's the app running) and
  your browser shows the label designer.
- Keep that Terminal window open while printing.
  Closing it quits the app. Re-open anytime with the
  same file.

--------------------------------------------------------
LABEL SIZE LOOKS OFF?
--------------------------------------------------------
Power the printer OFF. Hold the FEED button. Power it ON
while still holding FEED. Release after it feeds 1-2
blank labels. That re-calibrates the label size.

In the app you can also pick the label size (60x40 or
40x30) and use the "Shift left / right" slider to center
the print.

--------------------------------------------------------
PRINTER NOT FOUND?
--------------------------------------------------------
Make sure it's plugged into USB and turned on, then run
"1. Setup (run first)" again.
